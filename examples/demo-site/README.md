# Demo house

A synthetic four-bedroom suburban house with a garage, the site the viewer opens when `JARVIS_SITE` isn't set (`npm run dev`) and the one the
end-to-end tests and CI run against. Everything here is generated by
[`tools/make-demo-site.ts`](../../tools/make-demo-site.ts) (`npm run demo-site`); edit the script, not these files. CI
regenerates it and fails if the committed copy differs.

A two-storey 12 × 9 m block (living room, kitchen and dining, hall with the stair, powder room and study downstairs; the
primary suite with its walk-in closet and en-suite bath, two more bedrooms, a hall bath and the landing upstairs) and a
single-storey garage wing on the east (a two-car garage, a step down from the hall, and a laundry), each with its own
hip roof. [`docs/demo-house.md`](../../docs/demo-house.md) is its plan: the rooms, the panel schedule every breaker is
checked against, and what is in each room. The generator keeps each part of the house in its own file
([`tools/demo-site/areas/`](../../tools/demo-site/areas)).

It is meant to exercise most of the viewer with a small download (about 650 KB, so it renders at usable speed even in
software WebGL):

| File                       | What                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `site.json`                | the manifest: plan frame in metres, two storeys, eight viewpoints, a site layer (the pergola, key K), the furniture layer (F), every plugin                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `demo.glb`                 | the main model, meshopt-compressed: `Floor_<room>` nodes for 14 rooms, walls merged by storey with door and window openings, `Ceil_` ceilings, two hip roofs (`Roof_main`, `Roof_garage`), `Win_` / `WinFrame_` / `WinMull_` glazing, `Door_` leaves (one a sectional garage door), a stair, `Fixture_<id>` lights, wall plates, appliances and equipment as named nodes (the main panel, the water heater, the air handler, the washer and dryer, the heat pump…), rooftop solar, plants, a pond, a house-name plaque with a KTX2 (Basis) texture                                                                                                                           |
| `demo.parts.json`          | the parts file for the merged nodes (walls, stair, site, built-ins)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `furniture.glb` / `.parts` | an extra model on the furniture layer: the furniture of every room and the car in the garage, with floor, table and desk lamps that are light fixtures                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `ha_map.json`              | the Home Assistant fixture map (some fixtures unmapped, so `?ha=mock` invents entities for them)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `ha_controls.json`         | two scripts and a switch with a power sensor                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `ha_devices.json`          | the faults plugin's device map: devices placed by fixture, wall plate, registry item and area, and one unplaced                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `registry_pins.json`       | equipment registry pins (the main panel with its whole schedule in its specs, the monitor, the meter, the water heater, the EV charger, the battery and inverter, the heat pump, appliances…), linked to each other, one linked to fixtures and one placed by its room only                                                                                                                                                                                                                                                                                                                                                                                                  |
| `energy.json`              | the energy plugin's map, as a 16-channel circuit monitor (an Emporia Vue 2 stand-in, beside the main panel in the garage) would report it to Home Assistant through ESPHome: the grid → the main panel (its two mains clamps as legs A and B, the monitor's Balance as its Other) → a meter per clamped circuit (16; the unclamped ones are only in the Balance), each feeding what is on its breaker (registry pins, model nodes, wall plates, fixtures) and their rooms; a smart plug and the pond pump below their circuits; solar and a battery as roots; one low-confidence meter with a question. `?ha=mock` invents believable loads from the meters' labels: press J |
| `blueprints/`              | a floor plan per storey, drawn from the same wall data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

The Home Assistant URL is a placeholder: use `?ha=mock`. The house stands near Greenwich, London, for the sun.
